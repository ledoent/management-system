On a Security Control, set the **ISO 27001:2022 Ref** + **Theme**, then add the
**Implementing Privileges** that realise it. The **Resulting Groups** (every
group under those privileges) are surfaced read-only — the concrete access the
control is traced to.

Most controls (policies, training, physical) have no privilege analog and stay
unmapped — that is correct, not a gap. The demo maps the access-control family
(A.5.15/5.18/8.2/8.3) to the Management System privilege as an illustration.
